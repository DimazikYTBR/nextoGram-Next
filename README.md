# NextoGram

Свой клиент Telegram на Electron + GramJS (MTProto).

## Запуск

1. Установи Node.js (18+): https://nodejs.org
2. Получи `api_id` и `api_hash`: https://my.telegram.org → API development tools
3. В папке проекта:

```
npm install
npm start
```

4. В окне введи api_id, api_hash, номер телефона и код из Telegram (и облачный пароль, если он включён).

Сессия сохраняется в папке данных приложения (`%APPDATA%/nextogram/config.json` на Windows), повторно вводить ничего не нужно.

## Сборка .exe

```
npm run dist
```

## Важно

- Никогда не выкладывай `config.json` и свои `api_hash` / сессию на GitHub. Сессия = полный доступ к аккаунту.
- Для первых тестов лучше использовать запасной аккаунт: у Telegram жёсткие антиспам-лимиты на сторонние клиенты.
